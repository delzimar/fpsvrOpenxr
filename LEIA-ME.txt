========================================================================
           OpenXR Performance Overlay para VR (WMR / NVIDIA)
========================================================================

Um overlay de telemetria de hardware e desempenho de alto rendimento (GPU,
VRAM, CPU, RAM, FPS, FPS Médio, 0.1% Low, Latência e Frametimes) para jogos em
Realidade Virtual via OpenXR.

Projetado especialmente para simuladores (Automobilista 2, Assetto Corsa,
Assetto Corsa Competizione, rFactor 2, iRacing, Project CARS, etc.) e 
headsets Windows Mixed Reality (Samsung Odyssey, Odyssey+, HP Reverb G2, etc.).

------------------------------------------------------------------------
1. COMO INSTALAR / COMPARTILHAR
------------------------------------------------------------------------
1. Extraia todos os arquivos em uma pasta de sua preferência.
2. Abra o executável "OpenXROverlayManager.exe".
3. Clique em "ATIVAR OVERLAY NO OPENXR".
4. Pronto! O overlay agora iniciará automaticamente em qualquer jogo OpenXR.

------------------------------------------------------------------------
2. ATALHOS DE TECLADO NO COCKPIT (Dentro do VR)
------------------------------------------------------------------------
- Ligar / Desligar Overlay:       Ctrl + Shift + O
- Resetar Métricas (Méd/0.1%):    Ctrl + Shift + 0
- Aumentar Tamanho (+5%):         Ctrl + Shift + (+)
- Diminuir Tamanho (-5%):         Ctrl + Shift + (-)
- Mover para CIMA / BAIXO:        Ctrl + Shift + Seta Cima / Baixo
- Mover para ESQUERDA / DIREITA:  Ctrl + Shift + Seta Esquerda / Direita
- Aproximar / Afastar (Profund):  Ctrl + Shift + Page Up / Page Down
- Inclinar para Cima / Baixo:     Ctrl + Shift + Home / End

------------------------------------------------------------------------
3. JOGOS COM EASY ANTI-CHEAT (Ex: Le Mans Ultimate)
------------------------------------------------------------------------
Jogos com anti-cheat estrito bloqueiam injeção de DLLs externas não assinadas.
Quando for jogar Le Mans Ultimate:
- Abra o "OpenXROverlayManager.exe" e clique em "DESATIVAR OVERLAY".
- Quando voltar a jogar AMS2, Assetto Corsa ou outros, clique em "ATIVAR OVERLAY".

------------------------------------------------------------------------
4. COMPATIBILIDADE
------------------------------------------------------------------------
- VRs: Samsung Odyssey, Samsung Odyssey+, HP Reverb G1/G2, Lenovo Explorer,
       Dell Visor, Acer WMR e qualquer headset compatível com OpenXR (Meta Quest,
       Virtual Desktop VDXR, Pimax, etc.).
- Placas de Vídeo: NVIDIA GeForce (GTX 10xx, RTX 20xx, RTX 30xx, RTX 40xx).
- Sistema Operacional: Windows 10 e Windows 11 (64-bit).
