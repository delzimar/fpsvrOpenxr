OpenXR Performance Overlay for VR (WMR / NVIDIA)
========================================================================

A high-performance hardware telemetry and performance overlay (GPU,
VRAM, CPU, RAM, FPS, and Frametimes) for Virtual Reality games via OpenXR.

Designed especially for simulators (Automobilista 2, Assetto Corsa,
Assetto Corsa Competizione, rFactor 2, iRacing, Project CARS, etc.) and
Windows Mixed Reality headsets (Samsung Odyssey, Odyssey+, HP Reverb G2, etc.).

------------------------------------------------------------------------
1. HOW TO INSTALL / SHARE
------------------------------------------------------------------------
1. Extract all files to a folder of your choice.
2. Open the "OpenXROverlayManager.exe" executable.
3. Click "ACTIVATE OVERLAY IN OPENXR".
4. Done! The overlay will now start automatically in any OpenXR game.

------------------------------------------------------------------------
2. COCKPIT KEYBOARD SHORTCUTS (Inside VR)
------------------------------------------------------------------------
- Toggle Overlay On/Off:     Ctrl + Shift + O
- Increase Size (+5%):       Ctrl + Shift + (+)
- Decrease Size (-5%):       Ctrl + Shift + (-)
- Move UP:                   Ctrl + Shift + Up Arrow
- Move DOWN:                 Ctrl + Shift + Down Arrow
- Move LEFT:                 Ctrl + Shift + Left Arrow
- Move RIGHT:                Ctrl + Shift + Right Arrow

------------------------------------------------------------------------
3. GAMES WITH EASY ANTI-CHEAT (e.g., Le Mans Ultimate)
------------------------------------------------------------------------
Games with strict anti-cheat block the injection of unsigned external DLLs.
When playing Le Mans Ultimate:
- Open "OpenXROverlayManager.exe" and click "DEACTIVATE OVERLAY". - When you return to playing AMS2, Assetto Corsa, or others, click "ACTIVATE OVERLAY".

------------------------------------------------------------------------
4. COMPATIBILITY
------------------------------------------------------------------------
- VR Headsets: Samsung Odyssey, Samsung Odyssey+, HP Reverb G1/G2, Lenovo Explorer,
Dell Visor, Acer WMR, and any OpenXR-compatible headset (Meta Quest,
Virtual Desktop VDXR, Pimax, etc.).
- Graphics Cards: NVIDIA GeForce (GTX 10xx, RTX 20xx, RTX 30xx, RTX 40xx).
- Operating System: Windows 10 and Windows 11 (64-bit).
